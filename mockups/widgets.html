Widgets

Widgets only read; the phone owns the layout and refreshes on its own clock, so every widget shows a time, not a live count. Colour still lives only in sand cards. Tapping a widget opens the matching view; the checkbox in a row is the one control that works in place. A widget cannot hold the mic, so the talk widget and the lock screen control open the app already listening, and the capture widget opens it with the camera up.
